# Repository instructions

- Use Conventional Commits for every Git commit.
- Prefer the standard types `feat`, `fix`, `docs`, `test`, `refactor`, `perf`, `build`, and `chore`, with a scope when it adds useful context.
- Write the subject in the imperative mood and keep each commit focused on one coherent change.
- For Oatbase implementation, documentation, testing, release, or performance work, follow `.agents/skills/oatbase-development/SKILL.md`.
